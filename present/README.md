# 实时交互3D场景渲染系统

## 1. 项目概述

### 1.1 项目简介

本项目是一个基于WebGL2技术实现的实时交互式3D场景渲染系统。系统采用现代图形渲染管线，实现了完整的光照模型、复杂几何造型、实时动画以及用户交互功能。项目完全使用原生WebGL和JavaScript实现，不依赖第三方图形库，展示了从底层图形API到高级渲染技术的完整实现过程。

### 1.2 项目特点

- **完整的渲染管线**：实现从顶点着色器到片段着色器的完整图形渲染流程
- **高级光照模型**：支持方向光、点光源、聚光灯三种光源类型，使用Blinn-Phong光照模型
- **复杂几何造型**：支持球体、环面、立方体等多种几何体，支持动态生成和变换
- **实时动画系统**：支持物体旋转等实时动画效果
- **交互式控制**：支持鼠标拖拽旋转视角、键盘方向键控制、滚轮缩放、实时参数调整
- **性能优化**：实现了MSAA反走样、视锥剔除、深度测试等优化技术
- **实时性能监控**：显示FPS、绘制调用次数、三角形数量等性能指标

### 1.3 技术栈

- **图形API**：WebGL 2.0
- **编程语言**：JavaScript (ES6+)
- **着色器语言**：GLSL ES 3.00
- **数学库**：自实现矩阵和向量运算库

### 1.4 运行环境

- 支持WebGL2的现代浏览器（Chrome 56+, Firefox 51+, Safari 15+, Edge 79+）
- 无需安装额外依赖，直接在浏览器中打开index.html即可运行

## 2. 快速开始

### 2.1 运行项目

1. 将项目文件下载到本地
2. 使用现代浏览器直接打开 `index.html` 文件
3. 使用鼠标拖拽旋转视角，滚轮缩放场景
4. 通过右侧控制面板调整各种参数

### 2.3 房间场景说明

- 当前示例添加了一个“房间”场景：场景内创建了一个立方体房间，三个示例模型（球体、环面、立方体）放置于房间内部进行展示。
- 房间的前墙为半透明实现（便于观察室内），渲染时对前墙单独处理以获得正确的混合效果。
- 相机初始位置与缩放被限制在房间内部（通过 `ROOM_SIZE` 常量配置），避免视角移出房间。

### 2.2 操作说明

- **视角控制**：
  - 鼠标左键拖拽：旋转视角
  - 鼠标滚轮：缩放场景
  - 方向键（↑↓←→）：键盘控制视角旋转
  - 控制面板滑块：精确调整视角参数

- **光源控制**：
  - 勾选/取消勾选：启用/禁用对应光源（方向光默认开启）
  - 调整强度和颜色：通过滑块实时调整光源强度和RGB颜色
  - 光源可视化：点光源和聚光灯位置显示为发光球体

- **渲染选项**：
  - 线框模式：切换实体渲染和线框渲染
  - MSAA反走样：启用多重采样抗锯齿
  - 启用动画：开启/关闭场景动画

## 3. 核心功能

### 3.1 渲染功能

- 实时3D场景渲染
- 支持多种几何体（球体、环面、立方体）
- 支持模型变换（平移、旋转、缩放）
- 深度缓冲和面剔除

### 3.2 光照系统

- 方向光（Directional Light）- 默认开启
- 点光源（Point Light）带衰减 - 默认关闭
- 聚光灯（Spot Light）带软边缘 - 默认关闭
- Blinn-Phong光照模型
- 环境光、漫反射、镜面反射
- 光源可视化：点光源和聚光灯位置以发光球体显示

### 3.3 动画系统

- 物体旋转动画
- 可配置动画速度
- 可通过"启用动画"选项开启/关闭

### 3.4 交互功能

- 鼠标视角控制
- 实时参数调整
- 性能监控显示

## 4. 性能指标

- **目标帧率**：60 FPS（现代浏览器中）
- **支持三角形数**：数万个（取决于硬件）
- **渲染优化**：深度测试、面剔除、状态缓存

## 5. 开发说明

本项目为课程作业项目，展示了以下技术要点：

1. **图形渲染基础**：顶点缓冲区、索引缓冲区、着色器编程
2. **变换矩阵**：模型矩阵、视图矩阵、投影矩阵、法线矩阵
3. **光照模型**：Phong/Blinn-Phong光照模型实现
4. **性能优化**：反走样、批处理、状态管理
5. **交互设计**：用户输入处理、参数实时调整
